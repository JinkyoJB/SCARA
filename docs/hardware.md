# 하드웨어

확정된 값과 그 근거. 코드의 단일 출처는 `sw/scara/config.py` 이고, 문서와
코드가 같은 값을 봐야 한다.

## 1. 기구

3자유도 수평 다관절(SCARA), RRR. 세 관절축이 모두 연직·평행이라 팔은
수평면 안에서만 움직인다. 중력은 관절 토크를 만들지 않는다(감속기 베어링에는
굽힘 모멘트로 걸린다).

### 1.1 기구학 — CAD 실측

| 링크 | theta offset [deg] | d [mm] | a [mm] | alpha [deg] |
|---|---|---|---|---|
| L1 | 0 | −23.5 | 250 | 0 |
| L2 | 0 | −20.5 | 250 | 0 |
| L3 | 0 | 툴에 따라 (미확정) | 150 | 0 |

- 베이스 오프셋 (설치면 -> 좌표계0) = +215.5 mm
- 최대 도달반경 650 mm
- 좌표계 기준면 = 각 관절 출력 플랜지면 = 그 관절이 구동하는 링크 판재 상면
  (링크1 215.5 / 링크2 192.0 / 링크3 171.5 mm, 베이스 판 바닥 = 0)

링크 길이는 감속기 출력 플랜지 원 피팅으로 CAD 검증했고 오차 0.05 mm 미만이다.
총 도달 650 mm 는 실물 실측과도 일치한다.

### 1.2 질량 특성 — DH 좌표계 기준

`HW/scara.yaml` 원본을 그대로 쓰면 안 된다. yaml 의 질량특성 좌표계는
(x=좌우, y=링크방향, z=연직)이고 DH 는 (x=링크방향, y=좌우, z=연직)이라
90도 어긋나 있다. 아래는 Rz(+90도)를 적용한 값이다. 부호는 CAD 기하로 판별했다
— Rz(-90도)면 세 링크 모두 COM 이 링크 밖으로 나가 물리적으로 불가능하다.

| 링크 | 질량 [kg] | COM [mm] (x 링크방향, y 좌우, z 연직) |
|---|---|---|
| L1 | 2.920 | (−74.99, 0.00, +47.26) |
| L2 | 2.499 | (−60.80, −0.01, +53.32) |
| L3 | 0.667 | (−59.90, −0.01, −150.44) |

x 가 음수인 것은 DH 좌표계 i 가 링크 말단(관절 i+1)에 있고 몸체가 −x 로
뻗기 때문이다.

관성텐서는 `config.LINK_INERTIA_KGM2` 에 있다 (COM 기준, DH 좌표계).

질량 3개는 재질 밀도를 몰라 CAD 로 검증할 수 없어서 SolidWorks 추출값을 쓴다.
조립 후 무부하 토크 실측으로 간접 검증할 것.

### 1.3 한계값

| 항목 | J1 | J2 | J3 |
|---|---|---|---|
| 최대 각속도 [deg/s] | 360.0 | 360.0 | 712.9 |
| 정격 각속도 [deg/s] | 180.0 | 180.0 | 356.4 |
| 연속 토크 [N·m] | 29.0 | 29.0 | 16.2 |
| 피크 토크 [N·m] | 95.0 | 95.0 | 48.0 |
| 컨트롤러 가동범위 [deg] | ±150 | ±115 | ±155 |
| 소프트웨어 한계 [deg] | ±149 | ±110 | ±154 |
| 최대 가속도 | 미확정 | 미확정 | 미확정 |

**속도 여유가 0이다.** 모터 최고회전수 ÷ 기어비가 감속기 허용 출력회전수와
정확히 같다 (PQ003-H: 6000/100 = 60 rpm = 한계 60 rpm). 궤적 생성 시 반드시
클램프한다.

**토크 병목이 축마다 다르다.** J1·J2 는 감속기(29 N·m), J3 는 모터(16.2 N·m)가
먼저 한계다. `JointDrive.continuous_torque_limit_nm` 이 둘 중 작은 쪽을 고른다.

컨트롤러 가동범위는 Designer 에 사람이 넣은 값이지 기구 실측값이 아니다.

소프트웨어 한계는 두 제약 중 좁은 쪽이다 — 컨트롤러 값에서 1도 뺀 완충과,
자기충돌이 절대 일어나지 않는 최대 박스(`SELF_COLLISION_SAFE_BOX_DEG`).
축마다 이기는 쪽이 다르다: J2 는 충돌 박스(110), J1·J3 는 컨트롤러 완충이다.
충돌 박스는 `tools/collision_map.py` 가 CAD 모델로 계산한다.

### 2.1 모터 — Panasonic MINAS A6 MSMF012L1

| 항목 | 값 |
|---|---|
| 정격출력 | 100 W |
| 전원 | 단상·삼상 200 V |
| 정격 / 최고 회전수 | 3000 / 6000 r/min |
| 정격 / 순간최대 토크 | 0.32 / 0.95 N·m |
| 엔코더 | 23bit 앱솔루트 (8,388,608 count/rev), 배터리 백업 다회전 |
| 로터 관성 | 브레이크 없음 4,800 / 있음 5,100 g·mm² |
| 프레임 | □38 mm, 저관성, 리드선 IP65 |
| 회전방향 초기설정 | 정방향 = CCW |

출력축 분해능은 J1/J2 약 4.29e-7 deg/count, J3 약 8.50e-7 deg/count.

**J1 브레이크는 무여자 작동형(전원 없으면 잠김)이고 유지용이다. 회전 중
제동은 못 한다.** 시퀀스는 서보 ON -> 해제 -> 동작 -> 정지 -> 체결 -> 서보 OFF.

### 2.2 드라이버 — MADLN05BE (MINAS A6BE)

제어 인터페이스가 **EtherCAT (CoE / CiA402)** 이다. 펄스열·아날로그 타입이 아니다.

| 항목 | 값 |
|---|---|
| 프레임 / 전원 | A 프레임 / 단상·삼상 200 V, 6 A |
| 지원 제어모드 | pp, pv, tq, hm, **csp**, csv, cst |
| 미지원 | **ip**, 풀클로즈, **STO**, FoE, Jerk, **SDO Complete Access** |
| 통신 | 100 Mbps, 응답주파수 3200 Hz, DC 동기 지원 |

- 사이클릭 제어는 `csp` (ip 미지원)
- PDO 는 `0x1600` / `0x1A00`. 엔트리 구성은 Designer 가 고정한다
- SDO Complete Access 미지원 -> 마스터가 서브인덱스를 개별 쓰기해야 한다
- **STO 미지원 -> 안전은 외부 E-stop·접촉기 회로로 구성한다**
- A 프레임은 회생저항 미내장. 필요하면 외장

### 2.3 감속기 — SEJIN iGB Power-Quadro PQ003

| 항목 | PQ003-H (J1/J2) | PQ003-M (J3) |
|---|---|---|
| 감속비 | 100 | 50.5 |
| 정격 출력토크 | 29 N·m | 28 N·m |
| 순간 허용 최대토크 | 102 N·m | 98 N·m |
| 허용 최대 출력회전수 | 60 rpm | 120 rpm |
| 백래시 | < 2 arcmin | < 2 arcmin |
| 비틀림 강성 | 8.5 N·m/arcmin | 5.3 N·m/arcmin |
| 정격수명 | 10,000 h | 10,000 h |

비연속 기동/정지 반복운동 기준 설계다. 연속운전은 정격의 60%(최대 70%) 이내로.

**역구동성**: 100:1 인 J1·J2 는 출력측에서 손으로 돌릴 수 없다. 마찰이 감속비만큼
증폭되기 때문이다. 50.5:1 인 J3 만 손으로 돌아간다. 영점 정렬 절차가 이것에
따라 갈린다.

## 3. 실측 기준선

무부하 토크 (지령 10도, 정격속도의 10%). **감속기 미장착, 모터 단독 상태**라
모터 코깅·베어링 마찰만 잡힌 값이다.

| | J1 | J2 | J3 |
|---|---|---|---|
| 관절측 보고 토크 [N·m] | 0.704 | 0.896 | 0.388 |
| 모터축 실제 토크 [N·m] | 0.00704 | 0.00896 | 0.00768 |
| 위치 추종 오차 [deg] | 0.000 | −0.002 | +0.005 |

세 축이 0.007~0.009 N·m 로 거의 같아 신뢰도가 높다. 정격(0.32)의 2.2~2.8%.

조립 후 실측 주행 토크는 J1 6.2 / J2 9.5 / J3 4.3 N·m 다. 조그 토크 가드의
문턱을 감속기 한계(29 N·m)가 아니라 이 값 기준으로 잡는 근거다.

측정은 3단계로 나뉜다:

    1단계 모터 단독      모터 코깅·베어링 마찰                (완료)
    2단계 모터+감속기    감속기 마찰 = 2단계 − 1단계
    3단계 전체 조립      기구 마찰 = 3단계 − 2단계 − 링크관성 x 각가속도

3단계의 관성항은 `HW/model/` 의 dynamics 로 계산한다. 최종적으로 StellaX 의
Friction Parameters 입력 근거가 된다.

## 5. 파일

| 경로 | 내용 |
|---|---|
| `HW/scara.yaml` | 원본 파라미터. 참고용 (좌표계가 DH 와 다름) |
| `HW/motors/`, `HW/reducers/` | 모터·감속기 파라미터 |
| `HW/model/` | 오프라인 해석 라이브러리. 런타임에 쓰지 않는다 |
| `HW/HWscar-V2.step` | 전체 조립체 CAD |
| `HW/HWscar-V2/*.obj` | 시각화용 메시. 충돌 모델의 근거이기도 하다 |
| `HW/hw_step_files/` | 단품 가공도면·STEP |

배포할 수 없어 저장소에서 제외했다. 각 제조사에서 받을 것.
